Introduction to Linked Lists

calendar_today Oct 24, 2023 timer 15 min read person Dr. Sarah Smith

1. Overview

A linked list is a linear data structure, in which the elements are not stored at contiguous memory locations. The elements in a linked list are linked using pointers as shown in the below image:

2. Key Concepts

  • Node: Each element of a linked list is called a node.
  • Head: The first node in a linked list.
  • Tail: The last node in a linked list, which points to NULL.
  • Next: A pointer/reference to the next node in the sequence.
warning

Important Note

Unlike arrays, linked list elements are NOT stored in contiguous locations; the elements are linked using pointers. This means searching for an element in a linked list takes O(n) time, whereas arrays allow O(1) access.

3. Advantages and Disadvantages

add_circle Advantages
  • Dynamic Size
  • Ease of Insertion/Deletion
  • Memory efficiency (no pre-allocation)
remove_circle Disadvantages
  • Random access is not allowed
  • Extra memory for pointers
  • Not cache friendly
